# ACT_Async

Code for reproducing experiments on asynchronous robot policy inference and action execution, prepared for a NeurIPS 2026 workshop publication.

The repository currently includes:

- `imitate_episodes_async.py`: training and asynchronous evaluation of Action Chunking Transformer (ACT) policies.
- `run_aloha_eval_async_cac.py`: asynchronous evaluation in a real-world ALOHA environment using a remote policy server.

Setup instructions, experiment configurations, and reproduction commands will be added as the repository is prepared for release.
